# Warp Commons research checks

Read the selected issue and primary sources. State the exact claim you are checking. Before you run calculations or edit code, list your assumptions and say what result would disprove the claim. Record this plan before starting and disclose any changes in the final report.

Keep the work local. Do not publish or open a pull request before the contributor reviews your draft. See [README.md](README.md) for the report and submission format.
